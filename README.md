# Garmin_Face

Garmin Connect IQ watch faces for the fenix 8 series.

- ConfigurableAnalog/ is the project: a data driven analog face with skins, configurable pages, weather and health pages, and a store release pipeline. See ConfigurableAnalog/README.md.
- SETUP.md describes the machine level toolchain (SDK, developer key, PATH). ConfigurableAnalog/SETUP.md has the build, test and release commands.
